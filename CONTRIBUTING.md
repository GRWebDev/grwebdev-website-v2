# Contributing to GRWebDev

First off, thank you for considering contributing to GRWebDev! We appreciate any time you contribute to this project.

## Code of Conduct

By participating in this project, you agree to abide by our [Code of Conduct](./CODE_OF_CONDUCT.md). We pledge to make participation a harassment-free experience for everyone.

## How Can I Contribute?

### Reporting Bugs

- **Check for existing issues:** Before opening a new issue, please search the Issues tab to see if it has already been reported.
- **Use a clear title:** Summarize the problem.
- **Describe the bug:** Include steps to reproduce, expected behavior, and actual results.

### Suggesting Enhancements

- **Check for existing suggestions:** See if someone else has already proposed the idea.
- **Explain the value:** Why would this enhancement be useful to most users?
- **Be specific:** Provide a step-by-step description of the suggested enhancement.

### Pull Requests

1. **Fork the repo** and create your branch from `main`.
2. **Setup your environment:** (Follow the README).
3. **Make your changes:** If you've added code that should be tested, add tests.
4. **Write a good commit message:** Use the imperative mood (e.g., "Adds new privacy policy link").
5. **Submit the PR:** Link it to any related issues.

## Development Setup

To set up your local development environment:

1. Clone your fork: `git clone https://github.com/GRWebDev/grwebdev-website-v2/fork`
2. Install dependencies: `npm install`
